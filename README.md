# BOOLIFY — Digital Logic Learning Studio

BOOLIFY is an interactive web application designed to help students understand Boolean algebra and digital logic through practical learning and experimentation.

## Features

- **Boolean Expression Simplifier** – Simplifies Boolean expressions using implemented Boolean algebra rules.
- **Step-by-Step Simplification** – Displays the simplification process to help users understand each step.
- **Truth Table Generator** – Generates truth tables for Boolean expressions.
- **Boolean Laws Reference** – Provides a reference to important Boolean algebra laws.
- **Logic Gate Simulator** – Interactive simulation of seven logic gates: AND, OR, NOT, NAND, NOR, XOR and XNOR.
- **Combined Gate Experiment** – Demonstrates how multiple logic gates can work together.
- **Practice Quiz** – Helps students test their understanding of digital logic concepts.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Expression Notation

The Boolean expression simplifier uses the following notation:

| Symbol | Meaning |
|---|---|
| `+` | OR |
| `.` | AND |
| `'` | NOT |

For example, `A.B'` represents A AND NOT B.

1. Clone the repository:
